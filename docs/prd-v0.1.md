## 1. 产品概述

### 1.1 产品定位

**一个支持人们从真实生活中学习英语、持续积累个人英语知识，并通过互动练习逐渐建立英语表达能力的产品。**

产品围绕一种学习方式展开，不以儿童、家庭或某个年龄段作为定位边界。儿童和成人都可以使用；纸质笔记与亲子 Weekly Game 是已有的具体实践。

### 1.2 核心理念

**Learn English from the real world.**

从真实世界中发现知识，在知识关联中理解语言，在持续使用中掌握语言。

学习者通过发现生活中的事物、记录真实经历，逐步建立自己的英语知识库。AI 帮助学习者理解、整理、关联和学习这些知识，并通过倾听和回应支持自主互动学习。

最终目标：让学习者能够用英语理解和表达真实世界。

### 1.3 学习方式：Name everything you see

**给你看到的事物说出英文名称。** 从眼前真实接触的东西出发，发现自己不会表达的内容，学习它，并在生活中不断遇见、回想和使用。

名称是学习的起点，随后可以延伸到事物的特点、相关动作，以及学习者想表达的事情。例如：

- 看见洒水壶，学习 watering can。
- 关联到浇花，学习 water the plants。
- 进一步尝试描述自己正在做什么。

同一种方式可以由儿童和成人使用。学习深度与所需帮助因个人而异，不能仅由年龄推断英语水平、阅读能力或自主使用能力，也不能用某一个家庭成员的情况代表所有学习者。

产品提供的持续支持是：让发现与学习更方便，通过互动帮助理解和表达，并让个人内容与学习记录不断积累。

### 1.4 核心原则

- **真实发现优先**：学习内容来自学习者实际接触的事物与经历。
- **知识属于个人**：每位学习者的发现、学习记录和掌握情况独立保存。
- **AI 辅助而不主导**：AI 可以解释、整理、关联和陪练，不凭空创造学习经历；选材由学习者或协助者决定，在亲子 Weekly Game 中保留家长的最终选择权。
- **连接已有学习习惯**：支持纸质笔记等现有记录和书写习惯，以数字能力补充声音、互动和长期积累；纸质本子不是所有学习者使用产品的前提。
- **支持自主互动**：学习者可以自己操作、开口和提问，需要时由家长或其他引导者协助。
- **从简单到复杂**：从单词逐渐扩展到短语、句子和日常表达。
- **记录不能成为负担**：允许只记一个名称，也允许补充照片、地点和丰富场景。

## 2. 产品背景与真实使用场景

### 2.1 从真实生活中学习英语

发起者本人也通过“Name everything you see”的方式学习英语，说明这一学习方式并非儿童专属。日常看见的事物和实际经历，都可以成为英语学习与表达的来源。

产品要支持从真实接触、发现不会表达的内容，到学习、互动练习和持续积累的过程。家庭中的 Home 主题是当前具体实践的起点，不限定全部学习场景。

在亲子情境中，发起者还指出：中国家庭中，孩子有组织的英语学习往往依赖培训班或课堂，而家庭缺少把真实生活持续连接到英语学习的支持。这是具体需求来源之一。

### 2.2 已经开展的 Weekly Game

这是一项已经实际进行的亲子活动，为产品提供具体使用证据，不代表所有学习者都必须按周学习或由家长组织：

1. 周六，让孩子自己寻找并记录家里的物品，例如柜子、洒水壶、飞行棋。
2. 在本子上从发现中选出 30 个物品。
3. 一个一个查询英文怎么写、怎么读。
4. 孩子把英文写进纸质本子，听发音并学习朗读。
5. 接下来的几天，孩子拿着本子寻找对应实物，再次读这些英文。
6. 有时孩子自己操作软件听读，有时家长帮助播放和学习。

30 个是当前家庭活动的实际数量，产品中的每周数量需要可配置。

### 2.3 已明确的问题

- **后续几天听读不方便**：本子保存了文字，但再次听对应发音仍需要借助其他软件，难以顺畅衔接找实物、读英语的活动。
- **零散查询难以积累**：现有查询过程难以形成持续拥有的个人英语知识库，在当前亲子实践中表现为孩子学过的内容未能持续积累。
- **孩子希望主动参与**：家长观察到，孩子更喜欢自己操作，通过一来一回的互动学习，而不仅是被动听播放。
- **朗读需要节奏支持**：需要慢速示范、调整播放速度及反复练习。
- **反馈需要基于实际朗读**：软件需要真正听孩子怎么读，再作出针对性的回应。

以上具体困难主要来自亲子实践。它们为产品设计提供依据，但不意味着所有成人或儿童都具有完全相同的使用习惯与困难。

## 3. 用户与角色

### 3.1 Learner（学习者）

每个学习者是独立的知识拥有者，拥有自己的：

- Discovery Records：发现记录。
- Personal Knowledge Base：个人知识库。
- Learning Progress：学习进度。
- Learning / Practice Records：学习与练习记录。
- Review History：复习历史。

学习者包括通过这种方式学习英语的儿童和成人。学习者可以自主发现、选择内容、学习和练习，需要时由家长或其他引导者协助。

产品围绕共同的“真实发现 → 学习理解 → 互动练习 → 持续积累与使用”过程设计，不把儿童、特定年龄或家庭身份作为产品定位的边界。第一版通过 Weekly Game 承载这一过程。不同学习基础与自主使用能力需要怎样的体验适配，仍需细化。

### 3.2 Parent / Guide（家长或引导者）

在亲子 Weekly Game 中，家长可以：

- 查看孩子发现的内容，协助记录和整理。
- 从候选内容中选择本周学习内容，设置每周数量。
- 陪同第一次查词、听读和纸质书写。
- 帮助播放或参与互动学习。
- 查看学习进度并引导复习。

家长自身也可以是独立学习者；其知识和记录与孩子分开。成人独立学习是产品支持的使用情境，不以前置绑定孩子或承担引导者角色为条件。其他引导者的协助方式与访问权限待细化。

## 4. 核心产品模块

以下模块描述产品整体的核心能力。第一版以 Weekly Game 为交付主线，串联其中的发现、选材、学习、互动练习、积累与复习能力；不意味着各模块的所有独立使用方式都在首版交付。具体首版范围见第 7 节。

### 4.1 Discovery：真实世界发现

学习者发现生活中的事物并记录下来。当前具体实践以 Home 为起点，发现地点与场景不限于家庭。

| 字段 | 示例 |
| --- | --- |
| 名称 | 花盆 |
| 地点 | 阳台 |
| 场景 | 家庭 / 阳台 |
| 描述 | 阳台上的花盆里种了一棵植物 |
| 发现者 | 当前学习者 |
| 发现时间 | 实际记录时间 |

不要求所有字段都填写。第一版需要有可用的手动录入方式，支持直接数字记录，也保留先写纸质本子、之后整理进系统的使用路径。

拍照识别、语音输入、扫描纸质 Notebook 是可逐步支持的记录方式，具体进入第一版的范围待确定。

### 4.2 Discovery Pool：发现候选池

- 每位学习者拥有独立候选池，保留原始发现信息。
- 学习者可以从中挑选学习内容；亲子 Weekly Game 中由家长协助选材。
- 未被选中的发现继续保留，不因本周没有学习而丢失。
- 示例：Home 共 80 个发现，本周选择 30 个，其余 50 个继续保留。

### 4.3 Knowledge Organization：知识组织与关联建议

AI 对已发现内容提供分类和关系建议，例如：

- 分类关系：Table、Chair、Cabinet 属于 Furniture。
- 场景关系：Plant pot 出现在 Balcony。
- 组成关系：Plant、Soil、Plant pot 之间的联系。
- 动作关系：Water 与 Plant。
- 语言关系：Water the plant。

这些是可由学习者或协助者确认、调整的建议。AI 可以提供延伸词汇和表达，但必须与真实发现区分，不能自动加入真实发现记录或学习清单。

例如，建议学习 Water the plant，不代表系统可以记录“学习者已经浇过花”这一事实。

### 4.4 Weekly Game：每周学习集合

每周集合是一种组织学习内容的方式，承接已有 Weekly Game 实践。它不是产品整体所有学习行为的必经入口，但第一版先围绕这一方式实现完整体验。脱离每周集合的独立发现即学等其他路径，其具体形态和交付顺序尚未确定。

- 学习者可以从自己的 Discovery Pool 中选材；在亲子 Weekly Game 中，家长拥有最终选择权。
- 每周形成独立的 Learning Set，记录主题、周次和学习内容。
- 数量可配置，不固定为 30。
- AI 可以基于已发现内容提出分组建议，不能通过未发现、未确认接触的对象凑数量。
- 本周集合支持第一次学习，也支持后续反复打开练习；周六首次学习是已有家庭活动的具体安排。
- 历周集合保留，能够回到过去学过的内容。

### 4.5 Knowledge Learning：初次学习与纸质书写

对学习者打开的发现内容或选入学习计划的内容逐项学习，提供：

1. 英文单词或表达。
2. IPA 音标。
3. 英式 / 美式发音信息与播放支持。
4. 正常速度、慢速及重复播放能力。
5. 中文释义。
6. 简单英文解释。
7. 贴合生活场景的简单例句。
8. 相关词汇和表达。

示例：

- 中文：花盆。
- 英文：Plant pot。
- 例句：The plant is in the pot.

英文展示需要方便有书写习惯的学习者对照写进纸质 Notebook。系统记录学习过程；纸质书写是受支持的路径，不是完成学习的必要条件。

### 4.6 Interactive Learning：自主互动学习

这是第一版的核心体验。学习者可以围绕自己的学习内容，与软件进行有回应的学习，需要时由家长或其他引导者协助。

#### 核心互动过程

1. 进入一个学习项或一段练习。
2. 软件示范并邀请学习者开口。
3. 软件等待、收听学习者的朗读。
4. 根据这一次实际朗读给出回应。
5. 必要时慢速、拆分或重新示范，邀请学习者再次尝试。
6. 适时继续或结束当前练习，保存记录。

#### 互动示例

以下以亲子场景为例，不是每次必须执行的固定脚本；成人自主练习同样遵循倾听实际朗读再回应的过程：

> 软件：听我读，watering can。你来试试。
>
> 孩子：Watering can.
>
> 软件：我们慢一点再试一次。Watering… can…
>
> 孩子：Watering… can…
>
> 软件：这次更清楚了，再连起来读一次。

#### 反馈要求

- 必须真正收听学习者的朗读，再提供与这一次表现相关的反馈。
- 支持正常语速与慢速示范，以及重复尝试。
- 鼓励应自然、具体，不能无论读成什么都机械地判定为“很好”。
- 未听清或识别不确定时，应请学习者重试，而不是编造评价。
- 互动节奏应允许学习者完成表达，避免持续打断。
- 具体纠音标准、容错程度和重复次数仍需细化。

互动学习不仅包含读音，还可以围绕当前内容理解意思、听示范、提出问题并尝试简单表达。第一版以已明确的示范、朗读、倾听、反馈与再练习为核心；其他互动的具体边界待细化。

### 4.7 Personal Knowledge Base：个人知识库

- 发现和学过的内容随持续使用积累，不停留在一次性查询结果中，也不要求按周组织。
- 可以找回某一周的内容，也可以找到过去学过的某个知识项。
- 再次练习已有内容时，能够延续该学习者已有的学习记录。
- 个人发现、学习与掌握情况不会因不同学习者学习同一词而合并，包括同一家庭的成员。
- 标准释义、音标、音频等基础内容可以复用。

发现进入候选池与正式建立个人 Knowledge 之间的时机、同一物品多次发现的处理规则，见待明确事项。

### 4.8 Learning Progress：学习进度

原始 PRD 提出的初步状态：

- Discovered：已发现。
- Selected：已选入学习计划。
- Learned：已学习。
- Practicing：练习中。
- Mastered：已掌握。

这些状态的具体流转与判定方式尚未确认。需要区分“某周任务已完成”与“个人知识已掌握”；一次听读或一次正确朗读不能直接等同于掌握。

系统需要保存学习、练习及复习记录，供个人进度查看和后续互动使用。

### 4.9 Review：复习与练习

复习围绕学习者自己的知识库和已有学习集合开展，支持回到真实事物或场景中再次听读、回想和表达，也保留接下来几天拿着本子找实物、再次听读的亲子实践路径。

初期候选形式包括：

- 回到本周或历史内容进行互动听读。
- 看中文说英文。
- 看图片说英文。
- 听发音选择单词。
- 单词与图片匹配。
- 用单词完成简单句子。
- 根据生活场景进行表达。

基础复习是第一版范围；除互动听读外，具体首发题型及安排规则待确定，上述列表不等于全部题型已承诺首发。

## 5. 核心业务流程

### 5.1 通用流程：真实发现到学习与表达

学习者在真实生活中看见事物或经历某件事 → 发现不会用英语表达的内容 → 记录发现 → 打开对应内容学习英文、含义与发音 → 互动练习 → 保存个人内容与学习记录 → 再次遇见时回想和使用，并逐渐延伸到动作、句子与生活表达。

这是产品整体的通用流程，不等同于首版交付流程。按周组织、家长协助和纸质书写分别服务于具体使用情境；第一版先通过 Weekly Game 实现这条学习闭环。脱离每周集合的直接学习等其他路径尚未确定交付安排，动作、句子等互动的首版具体边界见待明确事项。

### 5.2 亲子 Weekly Game：周六发现、选材和第一次学习

孩子自主发现家中物品 → 纸质或数字记录 → 进入个人候选池 → 家长选择本周内容 → 逐项查看英文、听发音 → 孩子写进 Notebook → 保存本周集合与学习记录。

AI 分类与关联建议辅助整理与选材，不应成为每条发现必须先完成的繁重步骤。

### 5.3 亲子 Weekly Game：接下来几天找实物、自主互动学习

孩子拿着 Notebook 找到物品 → 在软件中进入对应学习内容 → 听示范并开口 → 软件倾听并反馈 → 需要时慢读和再练 → 保存个人练习记录。

具体如何从本子或实物进入对应条目，尚未确定。

### 5.4 持续积累

持续产生新的发现，按需组织学习集合 → 既有内容继续保留 → 回顾、复习并在真实生活中使用 → 从单词扩展到短语、句子和生活表达 → 形成个人英语知识积累。

## 6. 核心数据概念

以下是业务概念，不是最终数据库设计。

| 对象 | 含义 |
| --- | --- |
| Learner | 独立的学习者与知识拥有者 |
| Parent / Guide Association | 家长或引导者与其可协助学习者之间的关系，权限待细化；独立学习者不需要以此关系作为学习前提 |
| Discovery | 学习者真实发现的事物或经历，保留原始记录 |
| Context | 发现地点和生活场景 |
| Knowledge | 属于某位学习者的英语知识项 |
| Shared Language Content | 可复用的英文释义、音标、发音等基础内容 |
| Relationship | 知识之间的分类、场景、组成、动作或语言关联 |
| Topic | Home、Food、Nature 等主题 |
| Learning Set | 组织学习内容的集合，已明确支持每周集合；其他组织形式待细化 |
| Learning Record | 学习行为及个人进度记录 |
| Practice Record | 一次互动练习的过程、反馈或结果记录，字段待细化 |
| Review Record | 复习行为与结果记录 |

个人记录独立保存是数据层面的核心约束。语音是否保存、保存什么及保留多久尚未决定，不能由“保存练习记录”推导为默认长期保存原始录音。

## 7. 第一版产品范围

### 7.1 交付主线：先实现 Weekly Game

**第一版先实现 Weekly Game 这一学习方式，而不是一次性交付产品支持的所有学习方式。** 围绕真实发现形成每周学习集合，完成选材、初次学习、后续互动练习、个人知识积累与基础复习的闭环。

已有亲子活动为这条路径提供具体实践依据；Weekly Game 本身不将学习者限定为孩子，学习者也可以自主组织每周内容。首版的页面、入口与交互设计应优先服务这条主线。

### 7.2 核心交付

1. 学习者及独立的个人知识空间。
2. 真实发现与场景记录、个人候选池。
3. AI 英文翻译、释义、音标和发音支持。
4. AI 分类与关联建议，支持人工确认或调整。
5. 学习者或协助的家长创建并保留每周 Learning Set，数量可配置。
6. 逐项初次学习，支持直接数字学习及对照纸质 Notebook 书写。
7. 发音播放、慢速及重复示范。
8. 由学习者自主操作、需要时由家长或其他引导者协助的互动学习，能够倾听朗读并针对性回应。
9. 个人知识的持续积累，以及学习、练习进度记录。
10. 基于已有个人内容的基础复习。

### 7.3 暂不优先

- Weekly Game 之外的其他独立学习方式，包括脱离每周集合的独立发现即学路径；后续具体形态与交付顺序待确定。
- 完整英语课程体系。
- AI 自主决定全部学习内容。
- 脱离个人内容的完整开放式 AI 口语陪练。
- 社交排行榜与复杂游戏化。
- 大规模英语考试体系。
- 面向特定人群或专门场景的完整定制体验，如考试、职场等专项体系；成人使用共同学习流程属于产品范围。

## 8. 产品成功标准

第一版重点观察真实使用结果，具体指标口径及目标值待确定：

- 学习者是否愿意持续发现、记录生活中不会用英语表达的内容。
- 学习者是否能自主完成选材和初次学习；在亲子场景中，家长是否方便协助组织。
- 后续几天是否能方便找到对应内容、听读和练习。
- 学习者是否愿意自己操作并主动开口互动。
- 软件是否能根据实际朗读提供可信、有帮助的反馈。
- 学习者是否能通过理解、发音和关联记住内容。
- 是否逐渐从单词走向短语、句子和生活表达。
- 个人内容是否持续保留，并在后续学习中再次使用，包括跨周回顾。
- 学习者是否愿意并能够在真实生活中使用学过的英语。

## 9. 待明确的产品与交付决策

以下问题不阻碍产品定位成立，但需要在对应设计、开发前明确：

| 主题 | 待明确事项 |
| --- | --- |
| 产品与平台 | 正式名称、首发平台、设备形态及技术栈 |
| 学习者与协助关系 | 账号方式、独立使用与协助使用路径、家长或引导者关联及访问权限；不同学习基础、阅读与自主使用能力的体验适配，不能仅由年龄推断 |
| 发现录入 | 第一版除手动录入外，是否支持照片、语音或扫描 Notebook |
| 练习入口 | Weekly Game 内首次学习、后续练习与历史回顾的具体入口；清单点选、语音寻找或其他方式；使用纸质笔记时如何快速进入对应内容 |
| 单词确认 | 物品名称有歧义时，如何确认具体所指与合适英文 |
| 内容与发音 | 释义及发音来源、英美音默认规则、变速交互 |

| 朗读反馈 | 判定依据、不同语音特点与学习基础的容错（包括儿童语音）、纠音方式、重试和结束规则 |
| 互动控制 | 开始收音、结束发言、未识别、暂停、跳过及退出方式 |
| 知识归档 | Discovery 转为 Knowledge 的时机、多次发现及重复选入规则 |
| 进度 | 状态作用范围、流转条件、掌握的判定及人工确认方式 |
| 基础复习 | 首发题型、复习内容选择和重复安排 |
| 记录保存 | 练习保存哪些信息，是否保存原始语音及其保留和删除规则 |
| 使用条件 | 网络要求、语音服务响应、异常中断后的继续方式 |

## 10. 长期方向

以“Name everything you see”为起点，持续支持儿童和成人从真实生活中的事物延伸到动作、经历和表达。亲子 Weekly Game 为具体设计提供实践依据，产品随着更多真实使用情境逐步完善。

第一版先实现 Weekly Game，后续再扩展其他支持这一学习理念的方式。Weekly Game 是产品的一部分，不定义产品的全部功能边界；其他方式的具体需求与优先级需另行明确。

长期形成能够理解个人生活背景、持续积累知识、建立语言关联并支持语言能力发展的 Personal Language Knowledge System。

**真实生活是来源，命名所见是起点，自主互动支持学习，个人知识持续积累，真实表达是目标。**
