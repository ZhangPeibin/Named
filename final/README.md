## Design baseline

- 47 pt top safe area and 34 pt bottom safe area.
- Primary controls are at least 48 pt; standalone secondary actions use 44 pt interaction regions.
- Warm ivory `#F5F2E9`, white surfaces, primary `#526B4B`, main text `#30372F`, secondary text `#646A60`.
- Restrained editorial type, real-life photography, clear visual hierarchy and bilingual learning content.
- Sample content tells one connected story: discovering a tree, describing a personal moment, and returning to its meaning and related knowledge.

The SVGs contain text, named layer groups, shapes and embedded photos; they can be imported into Figma for further editing. A hidden `interaction-guides` layer marks the intended touch regions, each at least 44pt. They are static visual artwork, not native Figma Auto Layout components or an interactive app. Fonts use Georgia, Helvetica Neue and PingFang SC, with system fallbacks.
